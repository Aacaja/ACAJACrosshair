# ACAJA —— Windows 准星覆盖工具

>[!NOTE]
> **当前版本 v1.0.1**：完整功能齐备（设置界面 / 托盘 / 热键 / 手柄 ADS / 按游戏自动切预设），见文末 [Roadmap](#roadmap)。

ACAJA 是一个 Windows 桌面准星覆盖工具，用 **Rust** 编写（`windows-rs` + Direct2D + egui），是原 [CrossHairLIN](https://github.com/liuroland55/CrossHairLIN)（小林の准星，Python/PySide6）的全新重写版。

可以在游戏画面上叠加自定义准星，**点击穿透**，不影响游戏操作。适用于没有准星、或想自定义准星样式的游戏（建议配合无边框窗口模式）。

## 相比旧版（Python 版）的核心改进

| 维度 | 旧版 (v3.1.0, PySide6) | ACAJA (Rust) |
|---|---|---|
| 产物大小 | 46 MB 单 exe | **~8 MB** 单 exe |
| 架构 | 全屏透明窗口 + 20FPS 定时重绘 | **事件驱动 + 只绘制准星小窗口**，静止时 ≈0% CPU |
| 渲染 | QPainter（CPU） | **Direct2D 硬件加速**（GPU 合成） |
| 设置界面 | PySide6 传统窗口 | **egui 现代化设置窗**（实时预览、中英切换、深浅主题） |
| 点击穿透 | `WindowTransparentForInput` | 原生 `WS_EX_LAYERED\|TRANSPARENT` 分层窗口 |
| 内置功能 | 8 种形状 | **14 种形状**、四象限多色、动态扩散、手柄支持、按游戏自动切预设 |
| 运行时依赖 | Python + PySide6 | 零依赖，双击即用 |

# 📖 使用教程

## 1. 下载与启动

1. 从 [Releases](https://github.com/Aacaja/ACAJACrosshair/releases) 下载 `ACAJA-v1.0.1-x64.exe`（或从 [Actions](https://github.com/Aacaja/ACAJACrosshair/actions) 最新运行 Artifacts 下载）
2. 双击运行，你会看到：
   - ✅ **设置窗口**（默认居中弹出，深色界面）
   - ✅ 屏幕中央出现**红色十字准星**（默认样式）
   - ✅ 右下角出现**托盘图标** 🔲
3. 设置窗口关闭后程序**仍然常驻**：准星留在屏幕，托盘可随时切换/退出

> 若屏幕中央没有准星，或想排查问题：查看日志 `%APPDATA%/ACAJACrosshair/acaja.log`。

## 2. 调整准星样式（核心操作）

设置窗口从上到下分为几个卡片区：

| 区块 | 你能做什么 |
|---|---|
| **实时预览** | 顶部棋盘格画布，所有改动**即时生效**并同步到屏幕 |
| **形状与样式** | 14 种形状（十字/圆点/方块/圆圈/空心十字/空心方框/空心十字加点/箭头/三角/V/T/四角括号/GapHair/自定义图片）、大小、粗细、透明度、旋转、**多色模式**（上下左右四臂独立配色）、中心缺口、中心点大小、描边 |
| **动态准星** | 开火扩散量、恢复速度、后坐力恢复指示条 |
| **位置** | 「屏幕居中」按钮、X/Y 微调、显示器编号（多屏时选屏） |
| **自定义图片** | 图片路径 + 缩放（需先在上方选「自定义图片」形状） |
| **快捷键** | 切换准星热键（如 `Ctrl+F1`）；右键切换（点击/按住） |
| **手柄** | ADS 模式（**按住隐藏** / 扣动切换 / 按住显示 / 关闭）、触发键（左/右扳机）、阈值（0-255，默认 30）、开火扩散 |
| **预设** | 管理多套配置：选预设 / 存当前 / 创建（克隆当前）/ 删除 |

**工作流**：调好参数 → 点「保存预设」→ 之后随时可用。不改则只存在内存里，下次启动用**已保存**的预设。

## 3. 手柄玩法（Apex 等瞄准射击游戏）

1. 连接手柄（Xbox 系原生支持；PS 手柄需 DS4Windows 模拟）
2. 设置窗口 → 手柄区块 → 选择 **ADS 模式**
   - **按住隐藏**（推荐 Apex）：按住左扳机/L2 → 准星自动隐藏；松开恢复
   - **扣动切换**：每扣一次切换显隐（适合 toggle-aim）
   - **按住显示**：反向（特殊习惯）
3. 可选：把「触发阈值」调低（更灵敏）或调高（防止误触）
4. 右扳机开火时若开启「开火扩散」，准星会随射击扩散后回弹

## 4. 按游戏自动切换预设（Crosshair X 同款）

程序检测前台窗口，当切到指定游戏 exe 时自动加载该游戏绑定的预设。

**手动配置**（配置文件在 `%APPDATA%/ACAJACrosshair/app.json`）：

```json
{
  "game_bindings": [
    { "exe": "r5apex.exe", "preset": "apex" },
    { "exe": "cs2.exe", "preset": "cs2" },
    { "exe": "VALORANT.exe", "preset": "valorant" }
  ]
}
```

- exe 名大小写不敏感；游戏窗口在前台时自动切换，切走时保持（不自动切回）
- 预设文件在 `%APPDATA%/ACAJACrosshair/presets/<名称>.json`，可直接复制备份

## 5. 全局热键

- 设置窗口 → 快捷键 → 输入格式如 `Ctrl+F1`、`Alt+Shift+C`（支持 Ctrl/Alt/Shift/Win + F1-F24、字母、数字、Space 等）
- 「切换准星」热键：游戏里随时按
- 「下一预设」热键（`hotkey_next_profile` 字段）可轮流切换预设
- 每个预设独立保存各自热键，切预设自动切换注册

## 6. 托盘与常驻

| 操作 | 效果 |
|---|---|
| 双击托盘图标 | 显示/隐藏准星 |
| 右键托盘图标 | 菜单：显示/隐藏准星、打开设置、退出 |
| 关闭设置窗口 | 程序继续常驻（准星+热键全部生效） |
| 退出 | 托盘菜单 → 退出（或设置窗口里没有退出按钮？有：关闭窗口不会退出，托盘退出才彻底退出） |

## 7. 旧版配置迁移

首次运行自动把旧版 CrossHairLIN（`%APPDATA%/CrosshairApp/*.json`）迁移为 ACAJA 格式（形状/大小/颜色/位置/热键/描边/手柄设置全字段映射），旧目录保留不删。

## 8. 常见问题

- **准星不见了两片空白？** 先看托盘图标是否还在（程序可能退出了）→ 双击托盘重新显示；还不行看日志
- **游戏里准星被遮挡？** 确认游戏是**无边框窗口**模式；独占全屏（D3D exclusive）无法覆盖（任何 overlay 工具都做不到）
- **手柄没反应？** 确认手柄是 XInput 模式；PS 手柄用 DS4Windows；阈值调低试试
- **PS/一些游戏有内置准星？** 在设置里把它调成"关闭显隐"或用「按住隐藏」模式在瞄准时隐藏自定义准星

# 架构

```
主线程    egui 设置窗口（v1.0.1 起必须在主线程创建，修复 UI 不显示问题）
消息线程  Win32 消息泵（托盘 / 全局热键 / RawInput 鼠标 / 前台检测 / 手柄事件）
渲染线程  D2D 覆盖层（事件驱动，空闲阻塞 ≈0% CPU）
手柄线程  XInput 轮询（250Hz）
```

```
src/
├── main.rs        # 入口 + 消息线程装配
├── lib.rs         # 品牌常量与应用目录
├── config.rs      # 预设 schema、原子 JSON 持久化、旧版迁移、热键解析（12 单测）
├── i18n.rs        # 中英双语
├── state.rs       # ADS 状态机 / 预设轮换（8 单测）
├── overlay/       # D2D 渲染（14 形状、四象限色、描边、旋转、扩散、自定义图片）
├── input/         # XInput 手柄（手动链接）+ RawInput 鼠标
├── system/        # 托盘 / 热键 / 前台检测 / 多显示器 / 开机自启
└── ui/            # egui 设置窗（预览画布、双语、主题、预设管理）
```

## 系统要求

- Windows 10 / 11（x64）
- 无任何运行时依赖
