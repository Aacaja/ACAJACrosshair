# ACAJA —— Windows 准星覆盖工具

>[!NOTE]
> **当前版本 v1.2.0**：完整功能齐备（设置界面 / 托盘 / 热键 / 手柄 ADS / 按游戏自动切预设），见文末 [迭代路线](#迭代路线功能优先--主程序保持绝对轻量)。

ACAJA 是一个 Windows 桌面准星覆盖工具，用 **Rust** 编写（`windows-rs` + Direct2D + egui），是原 [CrossHairLIN](https://github.com/liuroland55/CrossHairLIN)（小林の准星，Python/PySide6）的全新重写版。

可以在游戏画面上叠加自定义准星，**点击穿透**，不影响游戏操作。适用于没有准星、或想自定义准星样式的游戏（建议配合无边框窗口模式）。

> 开发/维护者请看 [AGENTS.md](AGENTS.md)（架构地图、验证方式、踩坑记录）与 [WORKLOG.md](WORKLOG.md)（逐轮变更日志）。

## 相比旧版（Python 版）的核心改进

| 维度 | 旧版 (v3.1.0, PySide6) | ACAJA (Rust) |
|---|---|---|
| 产物大小 | 46 MB 单 exe | **~8 MB 单 exe**（后台壳 ~2.8 MB） |
| 架构 | 全屏透明窗口 + 20FPS 定时重绘 | **事件驱动 + 只绘制准星小窗口**，静止时 ≈0% CPU |
| 渲染 | QPainter（CPU） | **Direct2D 硬件加速**（GPU 合成） |
| 设置界面 | PySide6 传统窗口 | **egui 现代化设置窗**（实时预览、中英切换、深浅主题） |
| 点击穿透 | `WindowTransparentForInput` | 原生 `WS_EX_LAYERED\|TRANSPARENT` 分层窗口 |
| 内置功能 | 8 种形状 | **22 种形状**、8 套风格模板、四象限多色、动态扩散、手柄支持、按游戏自动切预设 |
| 运行时依赖 | Python + PySide6 | 零依赖，双击即用 |

# 📖 使用教程

## 1. 下载与启动

1. 从 [Releases](https://github.com/Aacaja/ACAJACrosshair/releases) 下载 `ACAJA-v1.2.0-x64.zip`（推荐，含两个 exe），
   或从 [Actions](https://github.com/Aacaja/ACAJACrosshair/actions) 最新运行的 Artifacts 下载。
2. 解压后双击 `acaja.exe`，你会看到：
   - ✅ **设置窗口**（深色界面）
   - ✅ 屏幕中央出现**红色十字准星**（默认样式）
   - ✅ 右下角出现**托盘图标**
3. 关闭设置窗口后主程序**仍然常驻**：准星留在屏幕，托盘可随时开关。

> ⚠️ **两个 exe 必须放在同一目录**：`acaja.exe`（主程序/后台壳）与 `acaja-ui.exe`（设置界面）。
> 只复制了主程序时，点「打开设置」会提示「未找到设置程序 acaja-ui.exe」。

## 2. 调整准星样式（核心操作）

设置窗口左侧是分区导航，右侧是内容卡片，底部常驻「应用设置到主程序」按钮：

| 分区 | 你能做什么 |
|---|---|
| **形状样式** | 实时预览、8 套风格模板（Apex/Valorant/CS2/狙击…）、**22 种形状**、大小、粗细、透明度、旋转、**多色模式**（上下左右四臂独立配色）、中心缺口、中心点大小、描边 |
| **动态准星** | 开火扩散量、恢复速度、后坐力恢复指示条 |
| **位置** | 「屏幕居中」按钮、X/Y 微调、显示器编号（多屏选屏）、**吸附前台窗口** |
| **手柄** | ADS 模式（**按住隐藏** / 扣动切换 / 按住显示 / 关闭）、触发键（扳机 / 肩键 LB·RB）、阈值（0-255，默认 30）、开火扩散 |
| **快捷键** | 切换准星热键、**切换下一预设热键**、右键切换（点击/按住显示/按住隐藏） |
| **自定义图片** | 图片路径 + 缩放（需把形状选成「自定义图片」） |
| **预设** | 选/存/创建（克隆当前）/删除预设，以及**游戏绑定**（前台进程 → 自动切预设） |
| **系统** | 开机自启开关（写入当前用户注册表 Run 键） |

**工作流**：调好参数 → 点底部「应用设置到主程序」（或直接关闭窗口，会自动保存）→ 主程序立刻生效，无需重启。

## 3. 手柄玩法（Apex 等瞄准射击游戏）

1. 连接手柄（Xbox 系原生支持；PS 手柄需 DS4Windows 模拟）
2. 设置窗口 → 手柄 → 选择 **ADS 模式**
   - **按住隐藏**（推荐 Apex）：按住瞄准键 → 准星自动隐藏；松开恢复
   - **扣动切换**：每扣一次切换显隐（适合 toggle-aim）
   - **按住显示**：反向（特殊习惯）
3. 触发键可选：左/右扳机（模拟量，按阈值判定）或左/右肩键（LB/RB，数字量，按下即触发）
4. 右扳机开火时若开启「开火扩散」，准星会随射击扩散后回弹

## 4. 按游戏自动切换预设（Crosshair X 同款）

程序检测前台窗口，当切到指定游戏 exe 时自动加载该游戏绑定的预设。

**在设置界面配置**：预设分区 → 游戏绑定 → 填进程名（如 `r5apex.exe`）+ 选预设 → 「添加绑定」。
进程名可在任务管理器的「详细信息」标签页看到。

也可以直接改配置文件 `%APPDATA%/ACAJACrosshair/app.json`：

```json
{
  "game_bindings": [
    { "exe": "r5apex.exe", "preset": "apex" },
    { "exe": "cs2.exe", "preset": "cs2" },
    { "exe": "VALORANT.exe", "preset": "valorant" }
  ]
}
```

- exe 名大小写不敏感；游戏窗口在前台时自动切换，切走时保持（不自动切回）
- 预设文件在 `%APPDATA%/ACAJACrosshair/presets/<名称>.json`，可直接复制备份

## 5. 全局热键

- 设置窗口 → 快捷键 → 两个输入框：**切换准星**热键、**切换下一预设**热键
- 格式如 `Ctrl+F1`、`Alt+Shift+C`（支持 Ctrl/Alt/Shift/Win + F1-F24、字母、数字、Space 等）
- 保存后立即注册生效；被其它程序占用时不会生效（换一个组合即可）
- 每个预设独立保存各自热键，切预设自动切换注册

## 6. 托盘与常驻

| 操作 | 效果 |
|---|---|
| 双击托盘图标 | 显示/隐藏准星 |
| 右键托盘图标 | 菜单：显示/隐藏准星、打开设置、退出（菜单语言跟随界面语言） |
| 关闭设置窗口 | 主程序继续常驻（准星 + 热键 + 手柄全部生效）|
| 退出 | 托盘菜单 → 退出，或设置窗口底部「退出主程序」 |

## 7. 旧版配置迁移

首次运行自动把旧版 CrossHairLIN（`%APPDATA%/CrosshairApp/*.json`）迁移为 ACAJA 格式（形状/大小/颜色/位置/热键/描边/手柄设置全字段映射），旧目录保留不删。

## 8. 常见问题

- **准星不见了？** 先看托盘图标是否还在（程序可能退出了）→ 双击托盘重新显示；仍不行看日志。
- **点「打开设置」提示找不到 acaja-ui.exe？** 两个 exe 要放在同一目录（解压时别只拖主程序）。
- **托盘菜单点不动 / 菜单不消失？** 已在 v1.1.7 修复（弹菜单前把宿主窗口设为前台窗口）；请升级到最新版。
- **主程序偶尔报错后直接退出？** v1.1.7 起：内部错误会被捕获并自动恢复，且恒定写崩溃日志
  `%APPDATA%/ACAJACrosshair/acaja-crash.log`；若反复出现，请把该文件反馈给开发者。
- **游戏里准星被遮挡？** 确认游戏是**无边框窗口**模式；独占全屏（D3D exclusive）无法覆盖（任何 overlay 工具都做不到）。
- **手柄没反应？** 确认手柄是 XInput 模式；PS 手柄用 DS4Windows；阈值调低试试。
- **需要详细诊断日志？** 用 `acaja.exe --diag` 启动，会写 `%APPDATA%/ACAJACrosshair/acaja-diag.log`。

# 架构（v1.1.0 起：双进程）

```
主进程（后台壳 acaja.exe，~15MB 常驻，无 UI 框架）
├── 渲染线程：D2D 覆盖层（事件驱动，空闲阻塞 ≈0% CPU）
├── 消息线程：Win32 消息泵（托盘/热键/RawInput 鼠标/前台检测/手柄事件）
└── 手柄线程：XInput 轮询（125Hz）

设置 UI 进程（acaja-ui.exe，按需拉起，关闭即整套释放 ~65MB）
└── egui 设置窗；参数经 WM_COPYDATA 实时推给主进程
```

```
src/
├── bin/
│   ├── backend.rs  # 后台壳入口（覆盖层/托盘/热键/输入/主消息循环）
│   └── ui.rs       # 设置进程入口（单实例 + 主进程存活自检）
├── ipc.rs          # 双进程通信（WM_COPYDATA 负载编解码）
├── config.rs       # 预设 schema、原子 JSON 持久化、旧版迁移、热键解析
├── state.rs        # ADS 状态机 / 预设轮换 / 共享 preset
├── overlay/        # D2D 渲染（22 形状、四象限色、描边、旋转、扩散、自定义图片）
├── input/          # XInput 手柄（动态触发源）+ RawInput 鼠标（右键切换/开火）
├── system/         # 托盘 / 热键 / 前台检测 / 多显示器 / 开机自启
└── ui/             # egui 设置窗（预览、双语、主题、预设、游戏绑定、22 形状、8 模板）
```

- Windows 10 / 11（x64）
- 无任何运行时依赖

## 迭代路线（功能优先 · 主程序保持绝对轻量）

> 设计铁律：**主程序 `acaja.exe` 绝对干净轻量** —— 不链接 UI 框架、不加线程/轮询、不加系统级钩子、不引入新依赖；
> 一切重量级能力只进设置进程 `acaja-ui.exe`（用完即走，占用无所谓）。不做游戏内快速面板。

| 迭代 | 版本 | 主题 | 状态 |
|---|---|---|---|
| 1 | **v1.2.0** | 档案与编辑效率 + 液态玻璃界面 | ✅ 已完成（[Release](https://github.com/Aacaja/ACAJACrosshair/releases/tag/v1.2.0)） |
| 2 | v1.2.1 | 动态准星与射击反馈（后坐力曲线 / 连发累积 / 开火来源） | ⏳ 下一轮 |
| 3 | v1.2.2 | 多屏与游戏集成（吸附规则 / 每屏配置 / 进程自动识别） | ⏳ 排队 |
| 4 | v1.3.0 | 可用性打磨（配置备份回滚 / 便携模式 / 托盘预设子菜单 / 性能自检） | ⏳ 排队 |

### 迭代 1（v1.2.0）已完成内容

**功能（本轮重点）**
- **预设列表化管理**：激活 / 复制（`名字 副本`）/ 重命名 / 删除（内联二次确认）/ 导出 JSON / 从 JSON 导入；
  重命名会自动迁移引用它的游戏绑定，导入重名自动加序号。
- **预设名安全校验**：预设名会成为文件名，非法名（`../`、`\`、`:`、保留名如 `CON`、超长、控制字符）在界面上即时提示并被拒绝，
  杜绝写出配置目录之外的文件。
- **热键录制**：点一下输入框直接按组合键即录入（Ctrl/Alt/Shift/Win + 字母/数字/F1-F24/方向键/符号），Esc 取消、可一键清空；
  告别手打 `Ctrl+F1` 字符串。
- **显示器选择**：列出每台显示器的真实分辨率与主屏标记，一键把准星移到该屏中心（`-1` = 跟随前台窗口）。
- **自定义图片选择器**：原生文件对话框选图，显示文件名 + 一键清除（告别手填路径）。
- **模板画廊**：8 套风格模板改成缩略图网格，点图即套用。

**界面（同步交付）**
- Apple 液态玻璃视觉：无边框窗口 + 自绘标题栏（可拖动）、深空背板 + 柔和光斑、玻璃材质面板 + 镜面高光边、
  同心圆角、悬停微抬升、弹簧过渡动效、深/浅两套高级调色；Win11 上额外叠加系统圆角与亚克力背板（失败自动降级，界面本身自洽）。

### 迭代 2（v1.2.1）下一轮优化点

- 动态准星进阶：**每发后坐力曲线**（连发累积、单发增量、上限、恢复速率可调），扩散过程可视化预览；
- 开火来源独立开关（左键 / 手柄右扳机），避免只想用手柄时被鼠标误触发；
- 命中/开火闪烁指示（准星短暂高亮），以及扩散恢复的「指示条」样式选项。
- 明确不做：全局键盘钩子实现的「按住热键」（违反轻量铁律，用鼠标右键/手柄按住模式替代）。

### 迭代 3（v1.2.2）多屏与游戏集成

- 吸附规则增强：吸附到前台窗口的**工作区/客户区**、可调垂直偏移系数（现在固定 1/3）；
- 每显示器独立配置（显示器 → 预设绑定）；
- 游戏绑定「自动识别」：从运行中的进程里挑 exe，不再手填进程名；
- 「游戏不在前台时自动隐藏准星」开关。

### 迭代 4（v1.3.0）可用性打磨

- 配置自动备份（时间戳快照）与一键回滚；
- 便携模式（配置跟随 exe 目录，U 盘即插即用）；
- 托盘菜单预设切换子菜单（主程序内构建菜单，零新增线程）；
- 性能自检面板（设置进程侧采样主程序 CPU/内存，主程序零开销）；
- 双语与文档一致性审计、首次运行引导。
