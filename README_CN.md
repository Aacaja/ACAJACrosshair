# 小林の准星

[English](README.md) | 中文

一个 Windows 桌面准星覆盖工具,用 PySide6 写的。可以在游戏画面上叠加一个自定义准星,支持点击穿透,不影响游戏操作。

主要给没用准星的游戏、或者想自定义准星样式的玩家用。建议配合无边框窗口模式,全屏游戏下不一定能用。

## 功能

- **8 种准星形状**:十字、圆点、方块、圆圈、空心十字、空心方框、空心十字加点、自定义图片
- **点击穿透**:准星窗口不拦截鼠标事件,游戏照常操作
- **拖动定位**:切换到拖动模式后可以直接把准星拖到任意位置,位置会记住
- **自定义参数**:大小、粗细、透明度、颜色都能调,空心十字还能调间隙和线长
- **描边**:给准星加一圈描边,浅色背景下看得更清楚
- **自定义图片**:可以导入自己的准星图片,支持缩放和透明度
- **预设管理**:保存多套配置,随时切换,配置文件存在 `%APPDATA%/CrosshairApp/`
- **全局快捷键**:注册一个全局热键,在游戏里也能一键切换准星显隐
- **全局右键切换**(可选):用低级鼠标钩子实现,任何地方点右键都能切换准星。注意:会拦截全局右键,平时用的话比较影响正常使用,按需开启
- **全屏自动置顶**(可选):检测到前台切换到全屏窗口(比如游戏的无边框全屏)时,自动把准星重新提到最顶层,省去手动重置。注意:对 D3D 独占全屏无效(那是硬件级独占显示器)
- **系统托盘**:可以最小化到托盘后台运行
- **中英文界面**:支持切换

## 环境要求

- Windows 10 / 11
- Python 3.8+(运行源码)
- PySide6 6.4+

## 安装

```bash
# 克隆仓库
git clone https://github.com/liuroland55/CrossHairLIN.git
cd CrossHairLIN

# 装依赖
pip install -r requirements.txt

# 运行
python crosshair_pyside6.py
```

不想装 Python 的话,可以直接去 [Releases](https://github.com/liuroland55/CrossHairLIN/releases) 下载编译好的 exe。

## 使用方法

1. 运行程序后,准星会自动显示在屏幕中央
2. 在左侧界面选形状、调参数,准星实时跟着变
3. 想换位置就点「拖动模式」,拖完点回「正常模式」,位置自动保存
4. 调好后记得点「保存当前配置」,或者存成新预设
5. 需要在游戏里切换显隐的话,设一个全局快捷键

## 实现原理

核心就两点:

**1. 点击穿透**:用 PySide6 的窗口标志组合实现——无边框、置顶、工具窗口,再加上 `Qt.WindowTransparentForInput`,这样窗口可见但不接收鼠标事件,鼠标点击会直接穿透到下面的游戏窗口。

**2. 渲染**:全屏透明窗口 + QTimer 每 50ms 触发一次重绘,用 QPainter 画准星图形。

之前试过 Tkinter、PyGame、Win32 API、PyQt5,最后选了 PySide6,主要因为它的 `WindowTransparentForInput` 是原生的,点击穿透最稳定,渲染质量也不错。

全局快捷键用的是 Windows 的 `RegisterHotKey`,全局右键用的是 `SetWindowsHookEx` 装的低级鼠标钩子(`WH_MOUSE_LL`)。全屏自动置顶用的是 `SetWindowPos` 配合 `HWND_TOPMOST`。

## 配置文件

配置存在 `%APPDATA%/CrosshairApp/` 目录下,每个预设一个 JSON 文件。默认预设是 `default.json`,可以在界面里新建、加载、保存、删除预设,也可以改存储目录。

## 打包

```bash
python build_v3.1.0.py
```

这个脚本会用 PyInstaller 打包成单文件 exe,然后用 UPX 压缩(没有 UPX 的话会自动下载)。打包完会生成发布包目录和 zip。
